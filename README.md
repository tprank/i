### 📌 О проекте
**tprank rebirth** — это обновлённая и переосмысленная коллекция веб-пранков, которые активируются при помощи физических NFC-меток. Человек подносит телефон к наклейке, открывается сайт, и происходит всякое веселье: громкие звуки, мемные картинки, имитация системных ошибок.

### 🖼 Медиафайлы (CDN)
Все картинки, звуки и графические элементы (логотипы, баннеры, кнопки) вынесены в отдельный технический репозиторий. Это сделано для того, чтобы не засорять основной код пранков и обеспечить быструю загрузку медиа. 
Исходники медиафайлов лежат в репозитории на GitHub:

### 📂 Где хранятся пранки?
Все пранки хранятся прямо в этом репозитории. 
Каждый пранк — это отдельная папка с коротким названием (например, `c` для курицы, `d` для Димона). Внутри каждой такой папки лежит файл `index.html`, в котором прописан код конкретного пранка (картинка, звук и логика срабатывания). 

Благодаря хостингу **GitHub Pages**, каждая такая папка автоматически превращается в готовую веб-страницу. Именно поэтому ссылки получаются такими короткими: `tprank.github.io/i/c/`.

### 🛠 Технологии
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript
*   **Хостинг:** GitHub Pages
*   **Медиафайлы:** Отдельный технический репозиторий (CDN)
